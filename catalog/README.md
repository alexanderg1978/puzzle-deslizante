# Catálogo de imágenes

La app descarga `catalog.json` y las imágenes de `images/` desde este repo
(`raw.githubusercontent.com`). Para añadir una imagen basta con subir un JPG
cuadrado de 1024x1024 a `images/` y una entrada en `catalog.json`
(`id`, `title`, `credit`, `file`). Solo imágenes de dominio público o CC0.
